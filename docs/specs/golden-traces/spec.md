# Spec: Golden turn traces (Wave 4 prerequisite)

- **Status:** Implementing
- **Branch:** `op_clean_crap`

## Objective

Record the exact `StreamEvent` sequences produced by the current engine for
the three canonical flows, so the Wave-4 `turn.rs` rewrite can prove
byte-identical behavior. No trace diff = no behavior change.

## Design

Add a test-only recorder at the `BoxedAgentEngine` boundary (the seam
`build_execution_engine` returns): a `RecordingEngine` wrapper that fans
events to both the real engine's sink and a capture buffer. Drive the three
flows through the existing in-crate harness
(`runner/core/test_support.rs::build_harness`):

1. **simple-qa** — single turn, respond
2. **stop-and-continue** — cancel mid-stream + continuation
3. **delegation-flow** — delegate → child respond → callback → continuation

Persist each capture as a checked-in fixture
(`tests/golden/<flow>.jsonl` — one StreamEvent per line, serde_json) plus a
companion test that replays the flow and asserts the live sequence matches
the fixture. Wave 4 keeps these tests green throughout.

## Acceptance Criteria

- [ ] AC1: Three golden fixtures checked in, generated by real engine runs
      (not hand-authored), each with a replay test that fails on any event
      diff (name, order, or payload field).
- [ ] AC2: Replay tests run in the normal suite; generation is a documented
      one-liner (test with `--ignored` or env flag).
- [ ] AC3: Fixtures are sanitized (no absolute paths, no timestamps — the
      recorder normalizes `timestamp` fields to sequence numbers).

## Boundaries

Test-only; zero production code change beyond the recorder seam being
feature-gated. No new deps.
