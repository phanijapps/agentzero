# T2 implementation review — 2026-07-15

## Blockers

**1. Primary actions bypass the configurable accent and can fail contrast.** `apps/ui/src/styles/components.css:8997`. The shared default button rule uses a fixed violet/blue gradient with white text. **Fix:** derive normal and hover states from `--primary`, `--primary-foreground`, and `--primary-hover`.

**2. The shared workbench has no tablet composition.** `apps/ui/src/styles/components.css:9127`. It only collapses below 768px, leaving desktop nested scrolling at tablet widths. **Fix:** add a tablet breakpoint that stacks workbench grids and resets constrained pane scrolling to normal document flow.

## Concerns

**3. Active navigation does not preserve the selected accent.** `apps/ui/src/styles/components.css:8953`. Its dominant treatment is hard-coded violet. **Fix:** derive active background and outline from `--primary`; reserve violet for non-semantic hierarchy.

**4. The theme default and AccentPicker default disagree.** `apps/ui/src/styles/theme.css:18`. Static and hydrated UI can start with different cyan accents. **Fix:** align the theme token to the picker default or update picker configuration and tests together.

**5. Card hover treatment is too broad.** `apps/ui/src/styles/components.css:8992`. Every card containing a button receives an interactive hover border. **Fix:** make the hover treatment opt-in through `.card--interactive` only.
