# Synthesis — root cause & remediation

## Root cause (cross-dimension)

zbot made **discovery probabilistic where it should be deterministic, and error text blind where it should teach**. The planner is contractually required to delegate by exact agent id (`AGENTS.md`: "assign only agents present in the live agent catalog") but its only discovery surface — `lookup_capabilities` — searches a catalog that **structurally cannot contain agents** (`build_planner_capability_catalog` emits `{skills, mcps, intent_guidance}`; no agents key), while the `available_agents` state that holds the roster is written for a `list_agents` tool that doesn't exist. The planner therefore re-phrases a semantic query 12× against a corpus that never answers it — not model stupidity, a **system-level information gap**. The same design blindness appears in tool errors: schema-only tool surfaces with zero example calls, and error strings that name the missing field without the correct shape ("Missing 'name' parameter" × 5 consecutive identical retries in one execution; ~237 ward-class errors historically). Weak-schema local models bind to in-context patterns, not JSON Schema; zbot gives them schema and prose errors instead of examples and affordances.

## Ranked remediation plan

|---|---|---|---|---|---|
| 1 | **Agent manifest in the planner prompt** + add `agents` to the planner capability catalog | The roster becomes deterministic, inline, complete — the 12-query search loop has nothing left to search for; the catalog gap closes for the fallback path | `invoke_bootstrap.rs:304` (catalog), planner prompt assembly in `builder.rs` / planner AGENTS.md template | **S** | lookup_capabilities: 25 calls/3 sessions, 100% planner → **0–2/session**; planner turns-to-first-delegation ↓ |
| 2 | **Example-line in the top-fumble tool descriptions** (ward, present_surface, update_plan, multimodal) | Prevents the shape fumble before the first error — the multimodal error-fix data point shows shape-teaching recovers in 2 calls; examples move that to 0 | `tools/ward.rs` (audience descs), `tools/present_surface.rs`, `execution/update_plan.rs`, `multimodal.rs` | **S** | ward-class errors ~237 → **−80%**; present_surface 54 → −60%; zero consecutive-identical retries |
| 3 | **Canonical server-side coercion** for the top 3 fumble shapes (string→array-of-one for multimodal content; bare ward name; plan-object→array) | Removes the error class for fumbles that have exactly one sane interpretation — no learning required | same files, `execute()` heads | **S–M** | shape-class errors → near-zero for coerced forms |
| 4 | **Error-as-affordance standard**: every `Missing 'X'`/`must be` error carries the minimal correct fragment; the failure-feedback hook (already tracks failing calls) echoes the tool's example line on 2nd failure | Makes the *remaining* error tail self-correcting in one retry regardless of model | `ward.rs`, `update_plan.rs`, `policy.rs` hook | **S** | retry distance after shape errors: 5+ identical → ≤1 |
| 5 | **Capability preamble at session start for root** (roster + core tools, ~300 tokens) | Same fix for the root actor before it develops its own lookup habit; lookup becomes long-tail-only (MCP/skill detail) | `invoke_bootstrap.rs` root prompt assembly | **S** | root lookup calls (currently ~0 in sample but rising with catalog gaps) stay 0; `lookup_capabilities` retained for MCP/skill long-tail |
| 6 | **Telemetry**: log provider/model on tool_result errors | Currently impossible to split error rates by model — blocks evidence-driven tuning of 2–4 per provider | trace emission at tool_result | **S** | model-attributed error table exists |

Sequencing: 1+2 together (one PR, both S, kill the two headline recurrences), then 3+4 (one PR), then 5+6. Total ~2 days. All are additive; the golden recall floors are unaffected (no recall-path changes); the 546-test suite covers the touched prompt-assembly and tool paths.

**The one-line version**: put the 7-agent roster where the planner is ordered to look for it, put example calls where the models bind their patterns, and make every error carry the shape of success — determinism for the fixed set, search for the long tail, affordances everywhere.
