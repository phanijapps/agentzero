## Concerns

**1. Early post-session spawn failures can orphan child sessions.** `gateway/gateway-execution/src/delegation/spawn.rs:223`. The AgentLoader and executor-builder error branches run after `Session::new_child` has persisted a `Running` child session, then call `handle_early_spawn_failure` and return before the normal cleanup that completes the child session at `gateway/gateway-execution/src/delegation/spawn.rs:1290`, so provider/agent/build failures can leave a phantom running subagent even though the parent callback and pending count are fixed. Fix: pass the child session id into the early-failure path for post-session failures, mark that child session terminal, and add a spawn-level test that forces an AgentLoader or executor-build failure and asserts the child session is no longer running.
